# P3.0b — ADL → XML-OPT Bridge (skiss)

**Status:** Placeholder. Körs inte i nuvarande sprint. Aktiveras efter P3.1.

## Scope

Komplettera Fas 3.0 med en konverter från archie-AOM (`OperationalTemplate`)
till EHRbase-accepterbart XML-OPT 1.4. När denna fas är klar producerar
`pnpm openehr:compile` riktiga OPT-filer från ADL-källor i `archetypes/`.

## Beroenden

- **P3.0** klart (compiler-skelett, archie 3.14.0 i pom.xml, EHRbase live).
- **P3.1** klart (composer mot fixtures). P3.1-rapporten ska besvara de tre
  frågorna i `PHASE-3.0-REPORT.md` sektion 8.3 (constraint-typer som faktiskt
  används, obligatoriska template-features, fixture-täckning).
- **CKM-licens-research** från sektion 8.2.1 (kan köras parallellt med P3.1).

## Strategi (att välja vid kick-off)

Tre options enligt `PHASE-3.0-REPORT.md` sektion "P3.0b — uppföljningsuppdrag":

1. Egen field-by-field-bridge i Java (~2 000–3 000 rader, deterministisk)
2. XSLT-transform på archies JSON-output (~1 000 rader, mer bräcklig)
3. Lyft motsvarande klass från ehrbase-internals (research-spike först)

**Default-rekommendation:** börja med Option 3 (1 timmes research). Om inget
hittas → Option 1 begränsad till de constraint-typer P3.1 visade behövs.

## Acceptanskriterier

1. `pnpm openehr:compile` producerar `body-temperature.opt` (riktig XML, inte diagnostic).
2. Output har `xmlns="http://schemas.openehr.org/v1"` + giltig OPT 1.4-struktur.
3. `pnpm openehr:load-templates` POSTar både compiler-output OCH fixtures till EHRbase
   med HTTP 201 (eller 409 = redan laddad).
4. Round-trip GET av compiler-genererad template returnerar XML strukturellt
   ekvivalent med Marand-genererad referens.
5. CompileMain bevarar samma CLI-kontrakt (input archetypes-dir, output OPT-XML).
6. Smoke-tester i `test/openehr.test.ts` utvidgas: `compiler-output-loads-into-ehrbase` +
   `compiler-output-vs-marand-fixture-structural-diff`.

## Estimat

- Option 3 (research-only): 0.5 session
- Option 1 (efter research, begränsad scope): 2 sessioner
- Option 2: 1–2 sessioner
- Worst case (full Option 1): 3 sessioner

## Risker

- Archie-API kan kräva uppgradering till 3.15+ för bridge-stöd → blockerande på Maven Central-publicering.
- AOM↔OPT-mappning för exotiska constraint-typer (recursion, slots) kan kräva mer kod än uppskattat.
- CC-BY-SA-tolkning kan tvinga licensjustering om ADL-filer inkluderas i compiler-image.
